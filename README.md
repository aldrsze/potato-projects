# Potato Projects

Personal project archive. Docs only — no code lives here.

## Structure

- `big-potato/` — long-term, multi-milestone projects
- `small-potato/` — small, quick projects

Each project is a folder containing:

- `PRD.md` — what and why
- `plan.md` — how, step by step
- `roadmap.md` — when, in order

Start a new project by copying `_template/`:

```sh
cp -r _template big-potato/my-project
```
